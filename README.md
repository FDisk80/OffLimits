OffLimits is a high-contrast, automotive-grade Speed Limit Head-Up Display (HUD) and driving assistant designed specifically for Android. Built from the ground up using Kotlin and Jetpack Compose, it provides drivers with real-time statutory and posted road speed limits, continuous GPS vehicle telemetry, proactive overspeed warnings, and cutting-edge display protection engineered for prolonged OLED/AMOLED dashboard use.




🚀 **Key Feature Categories**

- Authoritative Speed Limit Engine (OpenStreetMap Database)
- Authentic European Speed Limit Sign Display
- Advanced AMOLED Screen Burn-In Protection
- Overspeed Alerts & Audio Warnings
- Dual Orientation & Windshield HUD Projection
- Minimal, Distraction-Free Driver UI
- Local Speed Incident Log
